# Histórico do projeto

`experimentos_anteriores.zip` reúne os estudos Gemma e Qwen 2.5, os 45 testes de código anteriores, o relatório de 24/09 e a documentação usada durante a montagem da campanha Qwen3 Next.

Os estudos anteriores ajudam a entender o percurso, mas não entram nas médias da campanha principal. Para os resultados apresentados agora, use a pasta `avaliacoes` e o relatório em `entrega_resumida`.

O arquivo SANITIZACAO.json, dentro do histórico, identifica sete logs antigos cuja cópia compartilhável oculta identificadores de credenciais temporárias. Os hashes históricos se referem aos originais; as notas e respostas não foram alteradas. Os arquivos originais continuam na entrega anterior.
